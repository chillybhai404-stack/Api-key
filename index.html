AXU Interaction Intelligence API Documentation

Integrate AXU Intent Prediction directly into your FastAPI or microservice backend.

1. Predict Intent Endpoint (POST /predict)

Evaluates incoming message text and ranks predicted intent candidates against the selected threshold.

curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "The app crashes when I try to log in.",
    "threshold": 0.45,
    "top_k": 8
  }'

Response Format (200 OK)

{
  "model": "AXU-Intent-Classifier",
  "model_version": "2.1.0",
  "labels": [
    { "label": "bug_report", "score": 0.942 }
  ],
  "candidates": [
    { "label": "bug_report", "score": 0.942 },
    { "label": "technical_issue", "score": 0.312 }
  ]
}

2. Python Integration Example

import requests

response = requests.post(
    "http://localhost:8000/predict",
    json={"text": "Add offline mode", "threshold": 0.45, "top_k": 8}
)
print(response.json())
