About AXU Intelligence V2

AXU Interaction Intelligence V2 is an experimental text-intent prediction system. It analyses a message and ranks likely intent labels, such as greetings, questions, bug reports, feature requests, or mixed feedback.

How it works today

Incoming message→Intent prediction→Ranked labels

The current model is a classifier, not a generative large language model (LLM). Its scores are model outputs, not guaranteed probabilities, and it can misunderstand a message.

Where we're taking it

Predict intent→Select a response or action→Return a reply

Our planned next step is to use predicted intent to select an appropriate response, template, or tool, then show that response in the conversation. We'll test it against labelled examples and improve its handling of multiple intents and uncertain predictions.

The longer-term goal is a more capable conversational system. Intent routing and response selection are useful building blocks, but they do not alone make a system an LLM; generating flexible new language would require a generative model and additional training and evaluation.

Prototype status

This is an ongoing research prototype. The training examples are synthetic, so real-world performance still needs careful testing before the system is relied on.
